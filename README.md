# 🏦 Loan Approval Prediction System

## 📌 Overview
This project is a Machine Learning based web application that predicts whether a loan will be approved or rejected based on user details like income, credit history, and loan amount.

The application is built using Streamlit and provides both user and admin functionalities.

---

## 🚀 Features

### 👤 User Side
- Enter personal and financial details
- Get instant loan prediction (Approved/Rejected)
- View reason for decision

### 🔐 Admin Panel
- Secure login system
- View all applications
- Search applications by name
- Dashboard with summary metrics
- Data visualization (charts)
- Download data as CSV
- Clear all records

---

## 🧠 Machine Learning
- Model trained using supervised learning
- Uses features like income, credit history, loan amount, etc.
- Provides real-time predictions

---

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📊 Output
- Loan Approved ✅
- Loan Rejected ❌

---

This project is deployed using Streamlit Community Cloud.
